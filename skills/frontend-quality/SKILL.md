# Frontend/UI Design
- Preserve existing brand tokens, layout conventions, business logic and responsive behavior.
- Define ONE primary design direction for spacing, typography and colors. Do not stack contradictory aesthetic skills.
- Implement semantic HTML, keyboard navigation, visible focus, forms, loading states and reduced-motion preferences.
- For React use Vercel React Best Practices if installed. For design tasks choose one aesthetic director: UI/UX Pro Max OR Impeccable OR Taste.
- Inspect rendered desktop and mobile view with existing browser tools when possible. Do not invent visual verification.
- Confirm no navigation, content, analytics or performance regression. Report screenshot and test evidence.
